# Obesity Level Prediction using Machine Learning

## Project Overview
This project predicts obesity levels using lifestyle and health data.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- SHAP

## Steps Performed
1. Data cleaning and preprocessing
2. Handling missing values
3. Outlier detection using DBSCAN
4. Feature encoding (Label + One Hot)
5. Model training (LR, RF, KNN, SVM, Naive Bayes, XGBoost)
6. Model evaluation and comparison
7. Model explainability using SHAP

## Result
XGBoost achieved the best accuracy.
